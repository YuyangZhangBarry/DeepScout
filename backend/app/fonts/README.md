# Bundled fonts

Used as the Unicode-capable fallback for the fpdf2 PDF renderer when WeasyPrint is unavailable (see `backend/app/services/report_pdf.py`).

- DejaVu Sans 2.37 (Regular, Bold, Oblique) from the official release archive: <https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37>.
- License: see `LICENSE` (Bitstream Vera + Tavmjong Bah notices; DejaVu modifications are public domain). Permissive enough for distribution alongside this project.
